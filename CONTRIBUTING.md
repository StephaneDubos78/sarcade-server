# Contribuer à SARCADE Server

Le projet est en phase d'initialisation.

## Principes
- ouvrir une issue avant une évolution significative
- travailler via une branche dédiée et une Pull Request
- ajouter ou adapter les tests
- ne jamais committer de secret, mot de passe, certificat ou donnée opérationnelle réelle
- respecter la licence AGPL-3.0

La politique de contribution définitive (DCO ou CLA) reste à arrêter avant l'ouverture large aux contributions externes.
